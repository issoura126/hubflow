## 🚀 التثبيت السريع

### الطريقة 1: تحديث الملف فقط (موصى به)

```bash
# 1. فك الضغط
unzip n8n-pro-enhanced-v4.1-FIXED.zip

# 2. استبدل ملف app.js فقط
cp n8n-pro-enhanced-fixed/assets/js/app.js /path/to/your/n8n/assets/js/app.js

# 3. امسح cache المتصفح
# اضغط Ctrl+Shift+R في المتصفح
```

### الطريقة 2: تثبيت كامل

```bash
# 1. فك الضغط
unzip n8n-pro-enhanced-v4.1-FIXED.zip

# 2. انسخ جميع الملفات
cp -r n8n-pro-enhanced-fixed/* /var/www/html/n8n/

# 3. تعيين الصلاحيات
chmod -R 755 /var/www/html/n8n/
chown -R www-data:www-data /var/www/html/n8n/
```

## 🐛 حل المشاكل

### المشكلة: العقد لا تزال لا تتحرك

**الحلول:**
1. ✓ امسح cache المتصفح (Ctrl+Shift+Delete)
2. ✓ أعد تحميل الصفحة (Ctrl+Shift+R)
3. ✓ افتح Console (F12) وابحث عن أخطاء JavaScript
4. ✓ تأكد من استبدال ملف app.js بالكامل
5. ✓ تحقق من أن حجم الملف ~33KB (1049 سطر)

### المشكلة: Multiselect لا يظهر

**الحلول:**
1. ✓ تأكد من تحديث الصفحة بعد استبدال الملف
2. ✓ تحقق من Console للأخطاء
3. ✓ جرب فتح عقدة AI Text Analyzer
4. ✓ إذا لم تظهر checkboxes، استبدل الملف مرة أخرى

### المشكلة: عقد AI لا تعمل

**الحلول:**
1. ✓ تأكد من تشغيل Ollama: `systemctl status ollama`
2. ✓ جرب: `curl http://localhost:11434/api/tags`
3. ✓ تحقق من وجود نموذج: `ollama list`
4. ✓ في إعدادات العقدة، تأكد من عنوان Ollama الصحيح
