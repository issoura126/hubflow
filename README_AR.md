## 🎯 النودز الجديدة المدعومة بالذكاء الاصطناعي

<div dir="rtl">

### 1. 🤖 Ollama AI Node
تكامل شامل مع الذكاء الاصطناعي:
- **إكمال المحادثات** - محادثات ذكية مع سياق
- **توليد النصوص** - إنشاء محتوى من prompts
- **Embeddings** - إنشاء vectors للبحث الدلالي
- **إدارة النماذج** - سرد، تحميل، إنشاء نماذج مخصصة
- معاملات متقدمة: temperature، top_p، top_k، context window
- دعم Streaming للردود الفورية
- System prompts مخصصة وتحكم دقيق

### 2. 🔍 AI Text Analyzer Node
قدرات تحليل نصوص متقدمة:
- **تحليل المشاعر** - كشف المشاعر الإيجابية/السلبية/المحايدة
- **استخراج الكيانات** - استخراج الأشخاص، المنظمات، المواقع
- **استخراج الكلمات المفتاحية** - تحديد الكلمات المهمة
- **تلخيص النصوص** - إنشاء ملخصات موجزة
- **نمذجة المواضيع** - اكتشاف المواضيع الرئيسية
- **كشف اللغة** - تحديد لغة النص
- **تصنيف النصوص** - تصنيف المحتوى تلقائياً

### 3. 🖼️ AI Image Analyzer Node
ذكاء اصطناعي للرؤية وفهم الصور:
- **وصف الصور** - أوصاف تفصيلية للصور
- **كشف الأشياء** - تحديد الأشياء في الصور
- **OCR (استخراج النصوص)** - استخراج النصوص من الصور
- **تحليل الألوان** - تحليل الألوان السائدة
- **تحليل التكوين** - فهم بنية الصورة
- دعم نماذج LLaVA، Bakllava
- يعمل مع URLs، ملفات محلية، أو صور base64

### 4. ✨ AI Data Enrichment Node
تحسين البيانات بالذكاء الاصطناعي:
- **توليد الأوصاف** - وصف تلقائي للمنتجات والعناصر
- **توسيع الاختصارات** - تحويل الاختصارات إلى نصوص كاملة
- **التحقق من البيانات** - فحص جودة البيانات بالذكاء الاصطناعي
- **التصنيف التلقائي** - تعيين فئات ذكي
- **توليد Tags** - إنشاء وسوم ذات صلة
- **الترجمة** - ترجمة متعددة اللغات
- **استخراج الرؤى** - اكتشاف الأنماط والرؤى
- **توليد التنويعات** - إنشاء تنويعات للمحتوى

### 5. 💻 AI Code Generator Node
توليد أكواد احترافي:
- **توليد الأكواد** - من أوصاف باللغة الطبيعية
- **إعادة الهيكلة** - تحسين جودة الكود
- **تصحيح الأخطاء** - اكتشاف وإصلاح الأخطاء تلقائياً
- **شرح الأكواد** - فهم الأكواد المعقدة
- **تحسين الأكواد** - تحسينات في الأداء
- **توليد الاختبارات** - إنشاء unit tests تلقائياً
- **توليد التوثيق** - توثيق شامل للكود
- **تحويل اللغات** - الترجمة بين لغات البرمجة
- دعم: Python، JavaScript، TypeScript، Java، Go، Rust، PHP، وأكثر
- استخدام نماذج CodeLlama المتخصصة

## 🛠️ التثبيت

<div dir="rtl">

### الخطوة 1: تثبيت N8N Pro Enhanced

1. **تحميل المشروع**
```bash
# استخراج الملفات
unzip n8n-pro-enhanced-v4.0.zip
cd n8n-pro-enhanced
```

2. **إنشاء قاعدة البيانات**
```sql
CREATE DATABASE n8n_pro CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

3. **ضبط الإعدادات**
عدّل `includes/config.php`:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'n8n_pro');
define('DB_USER', 'your_username');
define('DB_PASS', 'your_password');
```

4. **تشغيل التثبيت**
افتح المتصفح: `http://localhost/n8n-pro-enhanced/install.php`

### الخطوة 2: تثبيت Ollama

#### على Linux:
```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

#### على macOS:
```bash
brew install ollama
```

#### على Windows:
حمّل من [ollama.ai](https://ollama.ai/download)

### الخطوة 3: تثبيت نماذج الذكاء الاصطناعي

```bash
# النماذج الأساسية لـ N8N Pro Enhanced

# ذكاء اصطناعي عام (مطلوب)
ollama pull llama3.2

# توليد الأكواد (موصى به)
ollama pull codellama

# تحليل الصور (لتحليل الصور)
ollama pull llava

# نماذج إضافية (اختيارية)
ollama pull mistral      # سريع وفعال
ollama pull mixtral      # استدلال متقدم
ollama pull phi          # خيار خفيف
```

### الخطوة 4: تشغيل Ollama

```bash
# تشغيل خادم Ollama
ollama serve

# التحقق من التثبيت
curl http://localhost:11434/api/tags
```

### الخطوة 5: اختبار الإعداد

1. افتح N8N Pro Enhanced: `http://localhost/n8n-pro-enhanced/`
2. أنشئ workflow جديد
3. أضف نود "Ollama AI"
4. اضبطه بـ prompt بسيط
5. نفّذ وشاهد السحر! ✨

## 📖 دليل البدء السريع

<div dir="rtl">

### مثال 1: تحليل محتوى بالذكاء الاصطناعي

**Workflow:**
```
[Webhook] → [AI Text Analyzer] → [Condition] → [Email Send]
```

1. **Webhook**: يستقبل محتوى نصي
2. **AI Text Analyzer**: يحلل المشاعر ويستخرج الكلمات المفتاحية
3. **Condition**: يتحقق إذا كانت المشاعر سلبية
4. **Email Send**: يرسل تنبيه إذا كانت المشاعر سلبية

### مثال 2: معالجة صور

**Workflow:**
```
[HTTP Request] → [AI Image Analyzer] → [Transform] → [MySQL Query]
```

1. **HTTP Request**: تحميل الصورة
2. **AI Image Analyzer**: وصف محتوى الصورة
3. **Transform**: تنسيق البيانات
4. **MySQL Query**: حفظ نتائج التحليل

### مثال 3: مساعد أكواد بالذكاء الاصطناعي

**Workflow:**
```
[Webhook] → [AI Code Generator] → [File Write] → [HTTP Request]
```

1. **Webhook**: يستقبل المتطلبات
2. **AI Code Generator**: يولّد الكود مع الاختبارات
3. **File Write**: يحفظ الكود المولّد
4. **HTTP Request**: يرسل إشعار بالإكمال

## 📊 نصائح الأداء

<div dir="rtl">

### تحسين Ollama
- استخدم **تسريع GPU** للحصول على استدلال أسرع 3-5 مرات
- احتفظ بالنماذج المستخدمة بشكل متكرر محملة باستخدام معامل `keep_alive`
- استخدم نماذج أصغر (llama2:7b، phi) للمهام البسيطة
- استخدم نماذج أكبر (llama2:70b، mixtral) للاستدلال المعقد

### دليل اختيار النموذج
- **llama3.2**: أفضل نموذج شامل
- **mistral**: سريع وفعال
- **codellama**: الأفضل لتوليد الأكواد
- **llava**: مطلوب لتحليل الصور
- **phi**: خفيف، جيد للمهام البسيطة
